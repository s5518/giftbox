# GiftBox

## サイト概要
### サイトテーマ
贈って喜ばれた、もらって嬉しかったプレゼントのレビューサイト
​
### テーマを選んだ理由
私はこれまで、友人や家族などにプレゼントを贈る際、相手の年齢や性別、関係性、予算などによって、何を贈ればいいのか迷うことが多くありました。
SNSなどで年齢や予算別のプレゼントをまとめた投稿を参考にすることもありますが、投稿者側の視点で紹介されているものが多く、実際にもらった人の感想も知りたいと感じていました。
そこで、実際にもらって嬉しかったプレゼントと、贈って喜ばれたプレゼントを共有し、年齢や予算などから自分の状況に近いプレゼントを探すことができるサイトを作りたいと考えました。
プレゼント選びに迷う人が、実際の体験を参考にしてプレゼントを選ぶことができるサイトを目指します。
​
### ターゲットユーザ
- プレゼント選びに迷う人
- 相手の年齢や性別、関係性、予算に合ったプレゼントを探したい人
- 実際にもらった人の感想を参考にしてプレゼントを選びたい人

### 主な利用シーン
- プレゼントを選ぶ時
- 実際にもらった人の感想を参考にしたい時
- もらって嬉しかった、贈って喜ばれたプレゼントを共有したい時
